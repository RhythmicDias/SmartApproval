Fast, Secure Medical Report Merging & Dispatch

A native desktop application built for pediatric neurology and clinical workflows to merge client medical reports, stamp details, and handle SMTP insurance approvals instantly.

Download Installer (.exe) Download MSI Package

Key Features

⚡ EMR-Only Dispatch

Skip the PDF merging. The new Fast-Path action lets you select clinical services, extract patient details directly from the medical report filename, and populate approval emails instantly.

🎨 Premium Dark Mode

Toggle between Light and Dark mode within General settings. Rest easy with a custom warm-charcoal aesthetic color palette matching the clinical branding.

✉️ Dynamic HTML emails

Dispatched approval requests are formatted in premium styled HTML with bold patient details and service links, rather than plain text, optimizing claims processing speed.

📈 Version Updates

Integrated update checking queries the GitHub Releases API dynamically to alert you immediately whenever a new release installer becomes available.

🔒 Secure local storage

All server credentials, SMTP passwords, and settings are saved completely locally in your OS profile directory. Safe, untracked, and offline.

📂 Visual Drag & Drop

Drag, drop, and rearrange files with grip handles to order pages before merging, ensuring clinical reports are organized perfectly.
