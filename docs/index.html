Fast, Secure Medical Report Merging & Dispatch

A native desktop application built for Neuropedia Clinicl to assist with clinical workflows to merge client medical reports, stamp details, and dispatch for insurance approvals instantly.

Download Windows (.exe) Download macOS (.dmg) Download MSI Package

Key Features

⚡ EMR-Only Dispatch

Skip the PDF merging. The new Fast-Path action lets you extract patient details directly from the medical report filename, select clinical services, and send for approval all in just 3 clicks.

🎨 Premium Dark & Light Mode

Toggle between Light and Dark mode within General settings. Rest easy with a custom warm-charcoal aesthetic color palette matching the clinical branding.

✉️ Dynamic HTML emails

Dispatched approval requests are formatted in premium styled HTML with bold patient details and service links, rather than plain text, optimizing claims processing speed, fullly customizable in the settings for both Insurance & non-insurance requests.

📈 Version Updates

Integrated update checking queries for new releases dynamically to alert you immediately whenever a new release installer becomes available.

🔒 Secure local storage

All server credentials, SMTP passwords, and settings are saved completely locally in your OS profile directory. Safe, untracked, and offline. SmartApproval does not store any user data online.

📂 Visual Drag & Drop

Drag, drop, and rearrange files with grip handles to order pages before merging, ensuring clinical reports are organized perfectly.
